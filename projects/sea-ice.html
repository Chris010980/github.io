Hudson Bay Sea Ice Monitoring

An automated geospatial processing pipeline for analysing daily satellite-derived sea ice concentration in the Hudson Bay region. The project combines data acquisition, GIS processing, time-series analysis and publication-quality visualisations.

Source code: github.com/Chris010980/hudson_bay_sea_ice_showcase

Project Overview

This project demonstrates an end-to-end scientific data processing workflow. Daily GeoTIFF products from the National Snow and Ice Data Center (NSIDC) are automatically downloaded, analysed and transformed into regional statistics and high-quality figures.

The complete workflow is fully reproducible and designed for automated daily updates.

Processing Pipeline

  1. Automatic download of daily NSIDC GeoTIFF products
  2. GeoTIFF validation and preprocessing
  3. Geographic masking of predefined Hudson Bay regions
  4. Calculation of ice-covered area and relative ice coverage
  5. Generation of maps, time-series plots and polar visualisations
  6. Automatic export for GitHub Pages
